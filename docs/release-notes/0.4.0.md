## Agent instruction files and the published specification

seiso 0.4.0 adds a document kind for coding-agent instruction files and checks
[Seiso Convention Specification 0.2.0](https://seiso.fog.moe/0.2.0/convention),
which is now published separately from seiso. The default rule set is
unchanged: KND001, KND002, LNK001, SUP001, and SUP002.

### New

- **`agents` kind**: instruction files for coding agents can declare or be
  mapped to `agents`, a long-lived kind whose
  [contract](https://seiso.fog.moe/0.2.0/convention#document-kinds) asks for
  commands, conventions, and boundaries. STL and VOX rules apply to it, while
  RAT, ORD, and MIX do not. `seiso init` maps `**/AGENTS.md`, `**/CLAUDE.md`,
  `**/SKILL.md`, and `.github/copilot-instructions.md` to `agents` when it
  finds a matching file to check.
- **Specification version**: `seiso --version` and the `conventionVersion`
  property of SARIF `tool.driver` name the specification version seiso
  checks. Rule pages link into the specification at its `spec-v` tag.

### Improved

- GitHub annotations name paths relative to the root of the Git repository
  that contains the workspace, so annotations from a check run in a nested
  workspace such as `docs/` attach to the right file. Outside a repository,
  they carry absolute paths. Other output formats keep workspace-relative
  paths.
- DUP003 and OWN002 look up each shingle's frequency once while ordering
  candidate prefixes, so checks that select either rule finish faster
  ([#73](https://github.com/scarletkc/seiso/issues/73) records measurements).
  Their diagnostics are unchanged.
- LNK002 accepts a `name` attribute on any HTML element as an anchor, as
  GitHub's repository view does for headings such as `<h3 name="config">`.
- EVD001 suggests linking the source or the dated record that holds a
  measurement, instead of adding a measurement next to the claim.

### Upgrade notes

- `seiso --version` prints `seiso 0.4.0 (Seiso Convention 0.2.0)`. A script
  that expects the line to be exactly `seiso VERSION` should read the second
  word instead.

### Known limitations

- Glob patterns that a child inherits through `extend`, including
  `extend-exclude`, resolve from the child's directory rather than the
  parent's ([#40](https://github.com/scarletkc/seiso/issues/40)). Fixing this
  will change which files those patterns match.
- KND001 reports unclosed YAML frontmatter for a document that starts with a
  thematic break followed by a labeled line such as `Note: ...`, even when
  configuration maps the document to a kind
  ([#74](https://github.com/scarletkc/seiso/issues/74)).
- Platforms other than those listed in the
  [README](https://github.com/scarletkc/seiso/blob/v0.4.0/README.md#install)
  have no prebuilt binary; install with `cargo install seiso`.
- Preview rules can change before promotion. Each rule becomes stable only
  after meeting the
  [evaluation policy](https://github.com/scarletkc/seiso/blob/v0.4.0/docs/evaluation/policy.md).

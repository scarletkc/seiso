## First public release

seiso 0.1.0 is the first public release of the Markdown convention and linter
for project docs written by AI and read by humans and agents. The earlier
`0.0.0` packages were placeholders; install 0.1.0 as described in the
[README](https://github.com/scarletkc/seiso#install).

### What's included

- **Convention**: every document declares one kind, such as `readme`, `howto`,
  `reference`, `adr`, or `changelog`, through frontmatter or path mappings in
  `seiso.toml`. The
  [convention](https://github.com/scarletkc/seiso/blob/v0.1.0/docs/reference/convention.md)
  defines each kind's contract.
- **Commands**: `seiso init` writes a configuration with suggested kind
  mappings, `seiso check` reports diagnostics, and `seiso rule` explains a rule
  with examples. `seiso policy`, `seiso index`, and `seiso parse` inspect
  effective policies, the workspace index, and the document model.
- **Stable rules**, enabled by default: KND001 and KND002 for document kinds,
  LNK001 for missing local link targets, and SUP001 and SUP002 for invalid and
  unused suppressions.
- **Preview rules**, enabled with `--preview`: stale values (STL001, STL003),
  pointers (PTR001, PTR002, PTR003), link anchors (LNK002), duplicated facts
  and ownership (DUP001, DUP002, DUP003, OWN001, OWN002), design-choice
  headings (RAT002), and conversation remnants (VOX001).
- **Output**: text, concise, JSON, SARIF, and GitHub annotations. `--fix`
  removes confirmed unused suppressions, and parse results are cached between
  runs.
- **Integrations**: a Claude Code PostToolUse hook (`seiso hook claude-code`),
  a pre-commit hook, and CI gates, described in
  [integrations](https://github.com/scarletkc/seiso/blob/v0.1.0/docs/guides/integrations.md).
- **Distribution**: `seiso` on crates.io and PyPI and `@scarletkc/seiso` on
  npm, each providing the `seiso` executable.

### Known limitations

- Prebuilt binaries cover Linux x64 and Windows x64. Other platforms build
  from source with a Rust toolchain.
- Preview rules can change before promotion. Each rule becomes stable only
  after meeting the
  [evaluation policy](https://github.com/scarletkc/seiso/blob/v0.1.0/docs/evaluation/policy.md).

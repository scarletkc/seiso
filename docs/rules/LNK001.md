# LNK001: Missing local link target

## What it checks

Reports a local Markdown link or image whose target is confirmed missing
inside the workspace. Reference links are resolved through their definitions.

## Basis

Consistency. A local path must resolve to an existing workspace entry: a
relative path from the document's directory, and a path starting with `/` from
the workspace root.

## Why it matters

After a configuration page is renamed, links from installation guides can
keep pointing to the old file. Readers reach a missing page instead of the reference.

## Example

```markdown
---
kind: howto
---

Read [the configuration reference](missing-reference.md).
```

## Instead

```markdown
---
kind: howto
---

Read [the installation steps](#install).

## Install

Run the installer.
```

## Exceptions

External URLs are outside this check. Paths outside the workspace, template
variables, and malformed URL escapes are left undetermined. Access failures
make the check incomplete. If a build generates a target that does not exist
in the checkout, suppress the link with a reason naming that build step.

Outside a documentation site, targets are matched as written: seiso does not
append `.md` or resolve `index.md`, and a leading `/` means the workspace root.
Letter case follows the filesystem: a link whose case differs from the file
passes on Windows and macOS but is reported on Linux.

## Inputs

Parsed Markdown links and image destinations, plus current filesystem
existence. A leading `/` resolves from the workspace root. Query strings and
fragments do not change the target path.
Excluded files, non-Markdown files, and directories can be valid targets.
Anchor validation belongs to `LNK002`.

In a document that a `[[sites]]` entry matches, a link also resolves as a
route of that site. The target is the first of these that exists:

1. the path as written;
2. for a leading `/`, the route after the site's `base`, from its `root`;
3. that route, or a relative path inside `root`, with `.md` or `.mdx` added,
   or with `index.md` or `README.md` inside it; a route ending in `.html`
   names its `.md` source, and `index.html` also names `README.md`;
4. for a leading `/`, the route from the site's `public` directory.

A route that is a directory counts only when none of its page sources exist.
Routes that leave `root`, and root-relative links outside `base`, resolve only
as written.

## Configuration

Select or ignore `LNK001` through `[lint]`. File discovery exclusions do not
exclude existing paths from being link targets. Declare the documents a site
generator renders with
[`[[sites]]`](../reference/configuration.md#documentation-sites).

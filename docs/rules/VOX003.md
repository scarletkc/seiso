# VOX003: Production narration

## What it checks

An implementation-process heading or first-person singular production narrative in a long-lived page.

## Basis

Product documentation describes resulting behavior. Production history belongs in a plan, decision record, or change record.

## Example

```markdown
---
kind: howto
---
## What I changed

I have implemented the connection panel.
```

## Instead

```markdown
---
kind: howto
---
## Connection panel

The panel lists active connections.
```

## Exceptions

Plans, ADRs, and changelogs may record implementation history. An implementation guide can legitimately use a matching heading; review the responsibility before applying the suggestion.

## Inputs

Visible headings and paragraph prose are read. Quoted phrases, explicit example sections, inline code, URLs, and code blocks are excluded.

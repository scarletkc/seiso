# SUP001: Invalid suppression

## What it checks

Reports a suppression comment with an unknown or incomplete rule code, a missing
reason, malformed syntax, or an invalid location.

## Basis

Consistency. Each exemption names full rule codes and explains why those checks
do not apply to its scope.

## Why it matters

A malformed exemption cannot express an effective policy. For example, a release
guide that uses a rule prefix can continue reporting the link it intended to
exempt, while readers assume that the exception was accepted.

## Example

```markdown
<!-- seiso: allow LNK -- The release creates this target. -->

Read the release guide.
```

## Instead

```markdown
<!-- seiso: allow LNK001 -- The release creates this target. -->

Read the release guide.
```

## Exceptions

Use `<!-- seiso: allow CODE, CODE -- reason -->` on its own line before the next
paragraph, list, table, code block, or heading. The same comment inside a
paragraph, list item, or table cell applies to that containing unit. A list-item
exemption includes its nested content; a table-cell exemption stays in its cell.

Use `allow-file` on its own line after frontmatter and before the first content
block to exempt a file. Leading HTML comments may precede it. Each declaration
requires distinct full codes and a nonempty reason on one line. Code examples
inside fenced blocks, indented blocks, and inline code have no effect.

A valid `SUP001` exemption can cover an invalid declaration. Invalid declarations
never suppress diagnostics, even when this rule is disabled.

## Inputs

Reads parsed HTML comments and block boundaries. Matches diagnostic primary
locations; related locations do not match. Block exemptions take precedence over
file exemptions. Among nested blocks the smallest scope wins; equal scopes use
the earliest declaration. No filesystem or workspace index is required.

## Configuration

Select or ignore `SUP001` through the rule selectors. There are no thresholds or
word lists. Disabling this rule hides invalid-declaration diagnostics without
making those declarations effective.

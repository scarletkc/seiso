# PTR002: Directory pointer

## What it checks

Reports a local link to a directory that is not a configured catalog.

## Basis

Heuristic. A directory is usually less specific than the document a reader needs.

## Why it matters

A link to a directory asks readers to choose the next file themselves.
A focused document link can take them directly to the relevant instructions.

## Example

In `guide.md`, with a `docs/` directory containing `setup.md`:

```markdown
---
kind: howto
---

Read [the setup instructions](docs/).
```

## Instead

```markdown
---
kind: howto
---

Read [the setup instructions](docs/setup.md).
```

## Exceptions

Changelogs and generated documents do not run this rule. External URLs,
unresolved templates, and paths outside the workspace are not diagnosed.
A maintained directory index can be declared in `catalog-dirs`.

## Inputs

Parsed link destinations and current filesystem directory status. This rule
does not guess that a README exists or inspect remote directory listings.

## Configuration

Enable preview and select `PTR002`. `[lint.ptr] catalog-dirs = ["docs/"]`
allows that exact directory, using the configuration [path base](../reference/configuration.md#path-bases).
Descendant directories are separate catalogs and require their own entries.

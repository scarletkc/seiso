# STL002: Deployment-state assertions

## What it checks

A deployment-state assertion with a completion, current-state, live-state, or production-environment signal in a long-lived page.

## Basis

Long-lived pages describe how to inspect deployment state. Dated release records preserve observations of what was deployed.

## Example

```markdown
---
kind: howto
---
The service is deployed to production.
```

## Instead

```markdown
---
kind: howto
---
Check the deployment dashboard to determine whether the service is deployed.
```

## Exceptions

Conditional instructions, quoted phrases, and assertions in explicit example/output sections are excluded. Dated plans, ADRs, and changelogs are outside this rule. A bare passive description such as “files are deployed to a branch” can be a procedure contract; it leaves the rule incomplete. English, Chinese, and Japanese phrase matching cannot determine the actual runtime state.

## Inputs

Visible prose and link labels are read. Inline code, URLs, code blocks, and comments cannot trigger a phrase.

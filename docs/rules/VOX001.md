# VOX001: Conversation remnants

## What it checks

A sentence contains a phrase addressing the requester of an earlier conversation, or reporting what that requester asked for, confirmed, or authorized.

## Basis

This normative rule applies to [long-lived documents](../../spec/convention.md#document-kinds). These documents address their readers directly and stand on their own.

## Why it matters

`As you requested` in an installation guide refers to a request the reader never saw and obscures whether the following instructions apply to them.

## Example

```markdown
---
kind: howto
---
As you requested, here's the updated installation guide.
```

## Instead

```markdown
---
kind: howto
---
Follow these steps to install the command-line tool.
```

## Exceptions

A quoted conversation may be necessary evidence. Suppress the quoted block with a reason identifying that evidence. Code examples containing these strings are excluded.

Product behavior that involves end users is excluded: a phrase whose clause states a negation, condition, requirement, or check before it, such as `未经用户授权`, `请确认用户已授权`, `once the user approved`, or `Verify that the user has authorized`, or a phrase followed by an attributive or temporal clause, such as `用户已授权的应用` or `经用户确认后`. Only the phrase's own clause counts: in `After the review, the user confirmed`, the earlier clause does not exempt the report.

## Inputs

Ordinary text and link labels are read. Inline code, URLs, link destinations, and code blocks are excluded. Formatting within prose can preserve a phrase, but code cannot join two otherwise separate phrase fragments. No filesystem or workspace index is required.

## Configuration

Use `lint.lexicon.<language>.extend-conversation-markers` to add phrases. Built-in phrases include `as you requested`, `the user confirmed`, `根据你的要求`, `经用户确认`, `用户已授权`, and `ご要望に応じて`. `lint.languages` selects the sentence languages to check.

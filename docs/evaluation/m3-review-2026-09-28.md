# M3 review corrections

Recorded on 2026-09-28. The review fixes evaluation portability, result-format
compatibility, and shared heuristic interpretation. The
[optimization evaluation](m3-optimization-2026-09-28.md) remains the record of
the earlier experiments. These corrections do not promote any rule.

## Changes

Implementation fingerprints normalize checkout line endings. Kind profiles bind
document bytes independently of the engine, and each evaluation records the
implementation it actually runs. Corpus and license hashes still cover original
bytes. Historical summaries consume explicit manifests instead of requiring the
current checkout or the original experiment directory layout. New source cohorts
require an explicit repository selection.

Replay comparison accepts added completeness metadata when the baseline predates
that field. Diagnostics, source identities, section annotations, and previously
recorded completeness values still participate in comparison.

Sentence and structural rules run in separate groups. Preamble and rationale
collection run only when their rules are selected. Decision headings share one
vocabulary, and structural interpretation uses the same quoted-assertion masking
as sentence rules. Missing main flow preserves incomplete ordering suppressions.

## Regression evidence

The [corpus replay](../../corpus/results/m3/review-v1/corpus/run.json) checks the
same 1,953 documents and preserves all 4,481 diagnostic objects, including the
one uncertain M3 diagnosis. Section annotations change in 75 places: 72 background
predictions become unclassified, one instruction becomes background, one becomes
reference, and one retains its role with different evidence. The known section
audit remains at 34/38 matching labels. These are development regressions.

The [history replay](../../corpus/results/m3/review-v1/history/run.json) checks
the same 155 changes and retains six VOX002 diagnoses. The
[25-document cohort replay](../../corpus/results/m3/review-v1/cohort/run.json)
uses the original kind profile with the corrected implementation and emits no
diagnoses. It is explicitly development data, not a fresh holdout.

Local validation passes 223 Rust tests, 145 Python tests, rustfmt, strict Clippy,
and the repository's stable check. Two opt-in corpus tests remain ignored.
The [replay verification](../../corpus/results/m3/review-v1/verification.json)
checks natural and historical results against this implementation, including
reversed input order. Focused tests cover newline portability, result-format
compatibility, manifest relocation, quoted rationale, shared decision headings,
and suppression preservation. No new performance acceptance or promotion is claimed.

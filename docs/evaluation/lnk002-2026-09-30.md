Recorded on 2026-09-30 for [issue 11](https://github.com/scarletkc/seiso/issues/11).

reviews. The sample and annotation gates pass; the precision gate fails and
source-diversity acceptance is pending. This is a completed evaluation with
a failed promotion gate, not an incomplete sample or a promotion claim.

## Gate and delivery decision

The [summary](../../corpus/results/lnk002/fresh-v1/summary.json) and
[decision receipt](../../corpus/results/lnk002/fresh-v1/decision.json) record a failed
promotion gate. At least 100 samples and complete dual review are satisfied;
96/451 is below 95%, and no owner diversity acceptance is assumed. Rule code,
preview status and rule documentation stay at the frozen implementation. No
promotion commit or promotion replay is performed. Fixing the findings requires
another fresh cohort before any later stable claim.

Vitest contributes 268/451 diagnoses (59.4%); the other six diagnostic-producing
sources contribute 183. The owner has been asked whether this concentration
is acceptable. Their later instruction to continue to delivery does not
accept diversity, so the recorded owner decision remains pending. The
sample was not extended, filtered or replaced.

Before future integration into `main`, rebase and replay every labeled batch.
Require byte-identical raw results and stop on any difference without
relabeling. That future integration check has not been performed: all PRs
remain unmerged and `main` is unchanged. LNK002 has a consistency basis,
so the heuristic usage-noise replay and concise-output agent trial do not apply.

Validation passed: 176 script tests including the 32 focused tool/evaluator
tests, 10 corpus tests and 11 oracle tests; 284 Rust tests with two original ignored
tests, build, rustfmt and Clippy; source/target Git and SHA-256 checks; complete
inventory verification; default/custom oracle compatibility; reverse-order
and literal-raw-byte replay; all 451 dual-label bindings and eight adjudications.
Rust local tests used an isolated temporary directory to avoid sandbox Git
injection. The repository Markdown check passed after this record was prepared.
At record preparation, final-commit CI and independent stage 7 acceptance
were pending. Delivery requires both to pass. The independent review receipt
and PR 55's exact-head CI result record their completed outcomes; the final
delivery response identifies the verified commit and checks. CI's platform
jobs run on Linux, Windows and macOS.
